模块一 · 认识 Claude Meet Claude

什么是 Claude？

Claude 是由 Anthropic 开发的 AI 助手。你可以像和一位知识渊博的同事聊天那样，用日常语言向它提问、请它帮忙——它能理解你的意思，并用文字回应你。

Claude 能帮你做什么

  • 写作与润色：邮件、报告、文案、演讲稿
  • 总结与提炼：把长文档、会议记录浓缩成要点
  • 头脑风暴：为方案、活动、命名提供创意
  • 翻译与跨语言沟通
  • 分析数据、解释概念、辅助你做判断
  • 写代码、查错、解释技术问题
ℹ 注意

Claude 不是搜索引擎。它擅长理解、推理和创作，而不是实时查询最新新闻或股价。当你需要处理某份资料时，把资料贴给它，让它帮你读、帮你写，效果最好。

它和普通软件有什么不同

传统软件需要你点按钮、填表格，按固定流程操作。和 Claude 协作时，你只要用自然语言说出想要什么，它就会理解并完成——没有菜单，没有固定步骤，对话本身就是界面。

🧠 自测：下面哪一项最适合交给 Claude 来做？
  1. 查询此刻北京的实时天气
  2. 把一份 20 页的报告总结成 5 个要点　✓
  3. 帮我把 1000 元转账给同事
  4. 远程控制家里的空调

Claude 最擅长理解和处理你提供的内容，比如总结、写作、分析。实时天气、转账、控制设备这类任务需要专门的工具或最新数据，不是 Claude 的强项。

✏️ 动手练习：发出你的第一条消息

  1. 打开浏览器，访问 claude.ai 并注册一个免费账号
  2. 在底部的输入框里输入：你好，请用三句话介绍一下你自己
  3. 按回车发送，读一读 Claude 的回复

与 Claude 的第一次对话

和 Claude 的互动就是一场对话：你发一条消息，它回一条，你可以继续追问、补充、修改要求。理解这个「来回」的节奏，是用好 Claude 的第一步。

一轮对话长什么样

在输入框里写下你的请求，按回车发送，这就是一条「消息」。Claude 会立刻开始回复。你们的每一次来回都留在同一个对话里，Claude 记得前面说过的内容，所以你不必每次都从头交代背景。

💡 提示

把 Claude 当成一位聪明但刚入职的同事：它很能干，但并不了解你的具体情况。你给的背景越清楚，它帮得越准。

不满意？继续追问就好

第一次回复很少是完美的，这很正常。你不需要重新开始，只要像和同事沟通一样接着说：「再正式一点」「太长了，压缩到 100 字」「加一个具体例子」。Claude 会在原来的基础上修改。

示例 Prompt
帮我写一封请假邮件，发给我的经理。

背景：我下周三因为家里有事需要请一天假，手头的工作会提前安排好。
语气：礼貌、简洁、专业。
🧠 自测：对 Claude 的第一次回复不满意时，最好的做法是？
  1. 删掉对话，从头重新开始
  2. 在同一个对话里直接告诉它哪里要改　✓
  3. 算了，自己动手改
  4. 换一个别的 AI 试试

在同一对话里追问，Claude 能记住上下文并在原基础上修改，这正是对话式协作最大的优势。

✏️ 动手练习：练习一次多轮对话

  1. 请 Claude 帮你写一段 50 字的自我介绍
  2. 收到后，回复「太正式了，轻松活泼一点」
  3. 再回复「加一句我喜欢的爱好」，观察它如何逐步调整

获得更好的结果

同样一个问题，提问方式不同，答案质量差别很大。好消息是：写出好提示词（Prompt）不需要任何技巧术语，只要把四件事说清楚。

好提示词的四要素

  • 角色：让 Claude 扮演什么身份，例如「你是一位资深 HR」
  • 任务：你具体想要它做什么，越明确越好
  • 上下文：相关背景、限制条件、受众是谁
  • 格式：你想要的输出长什么样，例如列表、表格、限定字数
★ 重点

你不需要每次都写全这四点。简单任务一句话就够；任务越复杂、越重要，多补充的信息就越能帮你拿到好结果。

对比一下

模糊的提问：「帮我写个活动方案」。清楚的提问见下方示例——它指定了角色、任务、背景和格式，Claude 就能给出可以直接拿去用的结果。

示例 Prompt
你是一位经验丰富的活动策划。

请为我们 15 人的市场团队设计一场半天的团建活动。
背景：预算每人 200 元，大家平时久坐、希望多互动，地点在市区。

请给出 3 个不同主题的方案，每个方案包含：主题名称、活动流程、预计花费。
🧠 自测：下面哪一项「不」属于好提示词的四要素？
  1. 角色
  2. 任务
  3. 上下文
  4. 对话时长　✓

四要素是角色、任务、上下文、格式。对话时长长短并不会影响结果质量。

✏️ 动手练习：改写你的提问

  1. 先用一句话向 Claude 提一个工作上的真实请求
  2. 记下它的回复
  3. 再按「角色 + 任务 + 上下文 + 格式」补全你的提问，重新发一次
  4. 对比两次结果的差别

桌面应用：Chat、Cowork、Code

除了网页版，Claude 还有桌面应用，把它放在你电脑触手可及的地方。桌面应用提供三种工作方式：Chat、Cowork 和 Code，分别对应不同深度的协作。

三种模式，三种场景

  • Chat：最基础的对话，问答、写作、头脑风暴都在这里
  • Cowork：让 Claude 在你的电脑上协助处理文件、跨应用完成任务
  • Code：面向写代码、运行和调试程序的场景
ℹ 注意

刚开始你只需要用好 Chat 就足够了。等熟悉之后，再去尝试 Cowork 和 Code，按需解锁更强的能力，不用一上来全部掌握。

桌面应用最大的好处是随手可用：配一个快捷键，无论你正在写文档还是浏览网页，都能立刻唤起 Claude，不必切换回浏览器。

🧠 自测：如果你只是想问问题、让 Claude 帮忙写邮件，应该用哪种模式？
  1. Chat　✓
  2. Cowork
  3. Code
  4. 以上都不行

日常问答和写作，用 Chat 就完全足够了。Cowork 和 Code 面向更复杂的文件操作和编程场景。

✏️ 动手练习：把 Claude 放到手边

  1. 访问 claude.ai/download，下载并安装桌面应用
  2. 登录你的账号
  3. 用 Chat 模式问一个今天工作中真实遇到的问题

模块二 · 整理工作与知识 Organizing your work

Projects 入门

当你围绕某件事反复和 Claude 打交道时——比如一个长期项目、一门课、一类重复的工作——Projects 能把相关的对话和资料集中在一个空间里，让 Claude 始终了解背景。

Project 是什么

Project 就像一个专属文件夹：你可以往里上传资料（文档、说明、参考），再写一段「自定义说明」告诉 Claude 这个项目的背景和你的偏好。之后在这个 Project 里的每一次对话，Claude 都会自动参考这些内容。

  • 把背景资料上传一次，之后不用反复粘贴
  • 用自定义说明固定语气、格式和角色
  • 把同一主题的多次对话集中管理
💡 提示

举个例子：建一个 Project 叫「周报助手」，上传公司的周报模板，写明「请用这个模板帮我整理每周工作」。以后每周只要把要点丢进去，Claude 就按模板输出。

🧠 自测：Projects 最大的好处是什么？
  1. 让回复速度更快
  2. 让 Claude 持续记住某个主题的背景和资料　✓
  3. 可以多人同时聊天
  4. 免费使用更多次数

Projects 把资料和说明集中存放，让 Claude 在该主题下始终了解背景，不必每次重复提供。

✏️ 动手练习：建一个你自己的 Project

  1. 在 Claude 里新建一个 Project，起个名字（例如「我的求职助手」）
  2. 上传一份相关资料（比如你的简历）
  3. 写一句自定义说明，例如「你是我的求职教练，请用鼓励的语气给建议」
  4. 在里面开一个对话，试试效果

用 Artifacts 创作

当 Claude 生成较长、可以独立使用的内容——一份文档、一段代码、一个表格、甚至一个小网页——它会把成果放进一个叫 Artifact 的独立窗口里，方便你查看、编辑和保存。

Artifact 解决了什么

在普通对话里，长内容会和聊天记录混在一起，难以复用。Artifact 把这类「作品」单独拎出来，显示在对话右侧。你可以直接在上面修改，或让 Claude 继续调整，改完一键复制或下载。

  • 文档、文章、长文案
  • 代码片段，甚至可以预览的网页
  • 表格、清单、结构化内容
ℹ 注意

不是每次回复都会生成 Artifact。只有当内容足够长、适合独立保存和复用时，Claude 才会用它。

示例 Prompt
帮我写一份「新员工第一周指南」，面向刚入职的同事。
包含：报到当天要做的事、第一周的学习重点、需要认识的关键同事。
请整理成清晰的分段文档。
🧠 自测：Artifact 最适合用来承载哪类内容？
  1. 一句简短的回答
  2. 一份需要保存和反复修改的长文档　✓
  3. 一个表情符号
  4. 一次随口的闲聊

Artifact 专为较长、可独立复用的成果设计，方便你编辑、保存和迭代。

✏️ 动手练习：做出你的第一个 Artifact

  1. 请 Claude 帮你写一份「本周待办清单」模板
  2. 在右侧的 Artifact 窗口里查看结果
  3. 让 Claude「把它改成表格形式」，观察 Artifact 实时更新

使用 Skills

Skills 让 Claude 掌握针对特定任务的「专长」——按照预设的标准流程和规范来完成某类工作，比如生成符合公司格式的文档、制作特定样式的图表。

Skill 是什么

你可以把 Skill 理解成给 Claude 的一套「操作手册」：里面写好了某类任务该怎么做、要遵守什么规范。需要时 Claude 会自动调用合适的 Skill，让结果更专业、更一致。

💡 提示

对新手来说，你暂时不需要自己制作 Skill。先知道有这回事就好——当你发现某类工作要反复以同样的标准完成时，Skill 就是为它准备的。想深入可以学习「Agent Skills 入门」这门课。

🧠 自测：Skills 主要解决什么问题？
  1. 让 Claude 回复更简短
  2. 让 Claude 按固定标准、专业地完成某类重复任务　✓
  3. 替你付款
  4. 加快网速

Skills 封装了特定任务的标准流程和规范，让 Claude 在该类任务上输出更专业、更一致的结果。

✏️ 动手练习：想一想你的场景

  1. 列出你工作中每周都要做、且格式固定的一类任务
  2. 想想如果有一套标准流程，Claude 可以怎样帮你自动完成
  3. 把它记下来——这就是未来你可能用上 Skill 的地方

模块三 · 拓展 Claude 的能力 Expanding Claude's reach

连接你的工具

通过集成（integrations），你可以把 Claude 和你日常使用的工具连接起来——Slack、邮件、日历、Google Workspace 等等——让 Claude 在这些工具里直接帮你干活，而不只是给文字建议。

什么是集成

集成是 Claude 和第三方应用之间的桥梁。配置好之后，Claude 可以读取你应用里的数据、执行操作——比如帮你起草并发送一封邮件、把会议总结自动发到 Slack 频道、在日历里添加日程。你不需要手动复制粘贴，Claude 直接在工具里行动。

常见的集成场景

  • Slack：让 Claude 总结频道消息、起草回复、管理提醒
  • 邮件（Gmail / Outlook）：自动起草邮件、整理收件箱、生成回复
  • 日历（Google Calendar）：查询日程、安排会议、生成议程
  • Google Workspace：在 Docs、Sheets、Slides 里直接操作内容
  • Zapier / Make：通过自动化平台把 Claude 接入几乎任何应用
  • Notion / Confluence：读取和更新知识库文档
💡 提示

如果你用的应用在 Claude 的官方集成列表里，优先使用官方集成，配置简单、权限清晰。没有官方集成时，Zapier 或 Make 这类自动化平台可以作为中间层把 Claude 接进去。

集成是如何工作的

每个集成本质上是给 Claude 开放了一组「动作权限」：读取数据、写入数据、触发操作。你在配置时决定开放哪些权限，Claude 只能在你授权的范围内行动。重要的操作一般会征求你的确认，你始终保持控制权。

🧠 自测：连接 Claude 和 Slack 集成之后，Claude 能做什么？
  1. 替你购买付费套餐
  2. 总结频道消息并起草回复　✓
  3. 删除你的 Slack 账号
  4. 监控所有员工

Claude 集成 Slack 后，可以在你授权的范围内读取消息、总结内容、帮你起草回复，而不会超出你设定的权限边界。

✏️ 动手练习：探索可用的集成

  1. 在 Claude 的设置或应用界面里，找到「集成」或「Integrations」入口
  2. 浏览可用的集成列表，选一个你日常用到的应用
  3. 按照引导完成授权配置，然后在对话里试着让 Claude 帮你完成一个真实任务

企业搜索

企业搜索让 Claude 能跨越组织内部的知识库、文档系统和数据源进行搜索，帮你快速找到散落在各处的信息，而不必一个个系统地手动查询。

它和普通搜索有什么不同

普通网页搜索只能找到公开内容。企业搜索连接的是你组织内部的数据——Confluence、SharePoint、Notion、Salesforce、内部数据库等等。Claude 不只是列出链接，而是读懂这些内容，给你直接可用的答案和总结。

典型使用场景

  • 查找内部政策或操作规范："我们的报销流程是什么？"
  • 跨库搜索项目资料："上季度关于 X 产品的所有会议纪要"
  • 整合多来源信息，生成综合报告
  • 快速定位某类合同或法律文件
  • 搜索产品知识库，辅助客服或销售
★ 重点

企业搜索的质量取决于你接入的数据源的质量和覆盖范围。接入的来源越全、内容越新，Claude 给出的答案就越准确。

权限与安全

企业搜索严格遵守原有系统的权限控制：Claude 只能搜索你本人有权访问的内容，不会因为你用了 Claude 就绕过原有的访问限制。敏感数据的保护机制不变。

🧠 自测：企业搜索和在 Google 上搜索最核心的区别是？
  1. 企业搜索更快
  2. 企业搜索能检索组织内部的私有数据　✓
  3. 企业搜索只能搜 PDF
  4. 企业搜索不需要账号

企业搜索连接的是组织内部的知识库和数据，而普通网页搜索只能访问公开内容——这是两者最根本的区别。

✏️ 动手练习：用 Claude 搜索你的内部资料

  1. 确认你的组织已连接了至少一个内部知识库到 Claude
  2. 在对话里问一个你平时需要去内部系统查询的问题
  3. 对比 Claude 的回答和你平时手动查询的效率，感受差别

深度研究模式

深度研究（Research 模式）是 Claude 的一项高级功能：它会自主进行多步骤的网络搜索和资料整合，针对你的问题生成一份结构化的深度报告，而不只是一个简短的回答。

什么时候用深度研究

当你需要的不是一句答案，而是对某个话题的全面梳理时，深度研究模式最合适。比如：为一份行业报告做背景调研、了解某项技术的发展现状、比较多种方案的优劣、梳理某个法规的关键条款。Claude 会自己决定搜什么、搜几次，直到有足够的信息来回答你。

如何使用

  • 在 Claude 的对话界面里，找到并启用「Research」或「深度研究」模式
  • 用清晰的问题或研究目标告诉 Claude 你想了解什么
  • 等待 Claude 完成多步搜索（可能需要几分钟），期间可以看到它的搜索过程
  • 收到报告后，仔细阅读并核对关键事实和引用来源
⚠ 警告

深度研究生成的报告内容丰富，但你仍然需要核查关键数据和引用。Claude 会标注信息来源，遇到重要结论请点开原始链接确认。AI 可能产生错误或过时信息。

如何得到更好的报告

研究目标越具体，报告越有针对性。比起「帮我研究一下 AI」，「分析 2024 年以来大语言模型在医疗诊断领域的主要应用案例及局限性」能让 Claude 搜到更相关的内容，生成更有用的报告。

示例 Prompt
请用深度研究模式帮我调研：
主题：中国零售行业的 AI 应用现状
重点：1) 头部零售商的实际落地案例 2) 主要应用场景（供应链/个性化推荐/客服）3) 面临的挑战
输出格式：分章节的综合报告，每个要点标注信息来源
🧠 自测：深度研究模式最适合哪种需求？
  1. 快速查询今天的天气
  2. 对某个复杂话题进行多步搜索和综合报告　✓
  3. 发一封邮件
  4. 修改一张图片

深度研究模式专为需要全面调研的任务设计，Claude 会自主多步骤搜索和整合信息，适合报告调研、竞品分析等场景。

✏️ 动手练习：完成一次深度研究

  1. 想一个你工作中真实需要调研的话题
  2. 启用深度研究模式，用清晰具体的语言描述你的研究目标
  3. 等报告生成后，重点检查它列出的信息来源，验证 2-3 个关键事实

模块四 · 融会贯通 Putting it all together

各职业的实战用例

Claude 不是只有一种用法。不同职业的人每天都在用它解决不同的真实问题——从写文案到分析数据，从准备法律文件到设计教案。这节课用具体场景告诉你，你的同行是怎么把 Claude 用进日常工作的。

市场与内容创作

  • 头脑风暴活动主题、起名方案、口号创意
  • 起草社交媒体文案，批量生成多个版本做 A/B 测试
  • 把一篇长文章改写成不同平台的格式（微信、小红书、LinkedIn）
  • 写新闻稿、产品介绍、落地页文案初稿

工程师与开发者

  • 解释陌生代码库，快速上手新项目
  • 写单元测试、生成 mock 数据
  • 调试报错，让 Claude 分析错误信息并给出修复建议
  • 生成技术文档、API 说明、注释

人力资源、教育与法务

  • HR：起草招聘 JD、面试问题、员工手册、绩效反馈模板
  • 财务：整理财报要点、生成数据摘要、起草投资人简报
  • 教师：备课大纲、课堂练习题、学生反馈评语
  • 律师与法务：整理合同要点、梳理法规条款、起草法律文件初稿（需专业复核）
ℹ 注意

在法律、医疗、财务等专业领域，Claude 的输出是草稿和参考，不能替代持牌专业人士的判断。重要决策请始终由相关专业人员最终审核。

🧠 自测：一位 HR 专员最可能用 Claude 完成哪项工作？
  1. 直接批准员工的报销申请
  2. 起草招聘职位描述和面试问题　✓
  3. 监控员工电脑
  4. 替代 HR 部门的所有职能

HR 最常把 Claude 用于起草文字性内容（JD、面试题、手册、绩效评语），节省重复的写作工作，再自己做最终审核和判断。

✏️ 动手练习：找到你职业里的高价值用法

  1. 列出你每周做 3 次以上的重复性文字或分析工作
  2. 选其中一项，把真实任务发给 Claude 试一次
  3. 评估它的输出：有多少可以直接用，哪里需要修改
  4. 把这个场景加入你的「Claude 常规用法」清单

其他协作方式

Claude 不只是一个答题机。它还能扮演思考伙伴、辩论对手、反思教练——帮你理清思路、检验想法、复盘决策。这节课介绍几种不那么常见但同样有价值的协作方式。

把 Claude 当作思考伙伴

当你面对复杂决策或模糊问题时，和 Claude 「大声思考」很有用。把你的困惑、想法、顾虑一股脑说给它听，让它帮你梳理逻辑、找出盲点、列出你没想到的角度。它不会替你做决定，但能帮你把混乱的思路变清晰。

示例 Prompt
我在考虑是否要跳槽。现在的工作稳定但成长空间有限，新机会薪资高 30% 但公司规模小、有一定风险。

请帮我梳理这个决策：列出我应该考虑的关键因素，帮我看清楚两边各自的核心风险，并提出 3 个我现在应该去弄清楚的问题。

语音功能

Claude 的桌面应用和移动端支持语音对话——你说话，它回应。不想打字的时候，或者边开车边想事情，语音模式让 Claude 更像一个随时在旁边的助手。

分享对话与协作

  • 生成对话分享链接，把 Claude 的分析发给同事或客户参考
  • 在 Project 里上传团队共用的资料，让团队成员各自和 Claude 交互
  • 把 Claude 写的草稿直接复制进协作工具（飞书、Notion、Google Docs）继续编辑
💡 提示

和 Claude 进行思考伙伴式对话时，不要只等它给答案——主动追问，让对话深入。「这里还有什么我没想到的？」「如果我错了，错在哪里？」这类问题往往能挖出最有价值的洞察。

🧠 自测：把 Claude 当思考伙伴使用，最核心的价值是什么？
  1. 它能替你做所有决定
  2. 帮你梳理逻辑、找出盲点、看清更多角度　✓
  3. 它比你聪明所以你该完全听它的
  4. 只适合聊工作，不能聊个人决策

Claude 作为思考伙伴的价值在于帮你梳理混乱的思路、发现盲点、列出你没考虑到的角度——决策权始终在你自己手里。

✏️ 动手练习：用 Claude 做一次思维梳理

  1. 找一个你最近有点纠结的问题（工作或个人都行）
  2. 把你的困惑、已知条件和顾虑完整地写给 Claude
  3. 让它帮你列出关键考量因素和你应该先搞清楚的问题
  4. 根据它的梳理，写下你自己的下一步行动
